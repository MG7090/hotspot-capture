# Hotspot Capture

تطبيق أندرويد لالتقاط ملفات صفحة تسجيل دخول Hotspot.

## المميزات
- فتح صفحة Hotspot داخل WebView مع تجاهل شهادات SSL الذاتية
- التقاط كل ملفات الشبكة (HTML, CSS, JS, صور, خطوط) تلقائياً
- تجاهل قيود CORS لأن الطلبات تتم داخل التطبيق
- تصدير كل الملفات في ZIP منظم بمجلدات

## كيف تحصل على APK بدون حاسوب

1. Fork هذا المشروع.
2. اذهب إلى تبويب **Actions**.
3. اختر آخر run ناجح.
4. حمّل APK من قسم **Artifacts**.

## البناء المحلي

./gradlew assembleDebug
